# 🩺 Medical Profile App – Backend

This is the backend service for the **Medical Profile App**, built using **FastAPI**.  
It handles health data processing, AI-based summaries, and acts as a bridge between the frontend and external services.

---

## 🚀 Tech Stack

- **FastAPI** – High-performance Python web framework
- **Uvicorn** – ASGI server
- **OpenAI API** – AI-powered medical summary generation *(planned & extensible)*
- **Python-dotenv** – Secure environment variable handling
- **CORS Middleware** – Enables frontend-backend communication
